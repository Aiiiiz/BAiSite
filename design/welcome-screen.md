# 欢迎界面

2026-10-18。首页增加可跳过的欢迎层，参考 [Sui — Internal Beyond](https://github.com/Sui-IB/InternalBeyond) 的全屏雾玻璃、左侧介绍、绘画工具与淡出入场体验。

## 视觉与行为

沿用纸白与石墨色，将原蝴蝶雾玻璃图片以中性灰展示，减少与博客正文的风格断裂。使用本站系统字体，不加载外部字体。背景图使用压缩 WebP，图片暂未加载时仍有纸白背景、完整介绍与可操作入口。

每个标签页会话首次访问首页显示欢迎层；进入博客、关闭、Esc 或选择关于/归档后记为已看过。首页页脚「重看欢迎页」可再次打开。直接打开文章、关于、归档或带锚点的首页时不拦截。禁用 JavaScript 时直接显示博客正文。

「擦雾」擦除雾层，「铅笔」绘制石墨色笔触，「清空」恢复画板；滑条分别控制雾气和笔触。画板支持鼠标与触摸，可整体关闭。画迹仅保存在当前页面内存中，刷新即消失，不发送到服务器。旋转手机或调整窗口时保留当前画迹。

原生 dialog 管理焦点和背景不可交互状态；进入后焦点回到正文。支持键盘按钮、滑条与 Esc；减少动态效果时立即进入正文。画板是可选装饰，不承担阅读或导航的必要功能。

## 修改位置

- 欢迎标题、介绍、背景路径与开关：`src/config/site.ts` 中的 `welcome`。
- 欢迎标题默认跟随 `site.title`，当前保留线上用户修改的站名「Z-A」；可在 `welcome.title` 单独覆盖。栏目说明为可选内容，不填写时不显示。
- 页面结构：`src/components/Welcome.astro`。
- 样式：`src/styles/welcome.css`。
- 交互：`src/scripts/welcome.ts`。
- 背景：`public/images/welcome-mist.webp`。
- 来源、许可和修改说明：根目录 `THIRD-PARTY-NOTICES.md`。

会话记录名为 `baisite:welcome:seen:v1`。测试首次体验可打开新的标签页会话、使用页脚重看入口，或仅清除该 sessionStorage 项；无需清空稍后读数据。

## 验收

检查首次访问、会话记忆、重新打开、Esc、关于和归档入口、文章直链、不支持存储与无脚本降级；检查擦雾、绘画、清空、画板开关、滑条、缩放与手机触控；检查四种屏幕宽度与减少动态效果。保留原有博客交互检查，并在 GitHub Pages 实际子路径下检查发布产物。
