# 此间 · 美术规范 v2

2026-10-18 · 现行博客规范 · 主题：纸白、石墨、光影。

本版本取代原 `art-direction.md` 中的配色与视觉装饰建议。保留 Dee’s Blog 带来的栏目索引、分组文章与图文交替布局；栏目仍为随笔、学习笔记、项目记录。原设计文件保留供追溯。

## 设计判断

用户更偏好 Apple 产品展示中简洁、理性、关注主体的理念。本网站据此减少颜色角色、装饰和字重变化，用明确层级、对齐与有节制的留白组织信息。艺术感集中在封面的形态、材质和光影，正文保持明亮、安静、易读。

六张示例封面被重绘为一套原创纸质形态研究。题材分别是留白、观察、笔记、文字、折光与秩序，使用相同背景、材质、左上光源、阴影方向与小尺度标记。采用矢量绘制，不使用游戏素材，也不对未来的真实照片统一施加灰度滤镜。

## 从《Clair Obscur: Expedition 33》借鉴什么

Unreal Engine 的开发者访谈提到，艺术负责人和创意负责人经过长期迭代使视觉方向一致；Belle Époque 等是其具体世界的灵感来源。[开发者访谈，2025-03-27](https://www.unrealengine.com/developer-interviews/inside-the-development-journey-of-clair-obscur-expedition-33)

Sandfall 联合创始人 Tom Guillermin 在 PlayStation 的开发过程文章中介绍了原型、垂直切片等阶段，以及共同素材构件的复用和重新组合。[开发过程文章，2026-03-11](https://blog.playstation.com/?p=416535)

下面是本项目对这些方法的转译，并非对游戏内部美术流程的完整复述：

| 方法 | 本网站的落地 |
| --- | --- |
| 先形成共同视觉方向 | 用「纸白、石墨、光影」限定所有界面与示例素材 |
| 先验证一个完整片段 | 先检查首页第一组封面与标题，再扩展到其他栏目和阅读页 |
| 复用共同构件 | 六张封面复用背景、纸张渐变、同向阴影与细线标记 |
| 在共同规则中变化 | 只变化纸的形态与构图，不再变化一整套颜色和画风 |
| 持续回看整体 | 同时检查封面组、首页、归档、文章、关于页与移动版 |

不引入游戏中的时代装饰、繁复金框、角色、标志、界面或暗色战斗氛围。借鉴的是统一视觉的方法，以及用明暗塑造材料的思路。

## 色彩职责

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--color-canvas` | `#F7F7F5` | 页面、侧栏与页头的共同底色 |
| `--color-surface` | `#FFFFFF` | 输入等少量独立表面 |
| `--color-ink` | `#252525` | 标题与正文 |
| `--color-muted` | `#686864` | 摘要、日期与辅助文字 |
| `--color-line` | `#DDDDD8` | 分隔线，不用于小字 |
| `--color-accent` | `#343432` | 链接、当前栏目与焦点 |
| `--color-fill` | `#EAEAE6` | 按下、选中与轻填充状态 |
| `--color-border-control` | `#858580` | 交互控件边界 |
| `--color-art-mark` | `#82745E` | 仅用于封面细线和极少量分隔标记 |

主体界面仅使用中性色。金属灰棕只占极小面积，不承担栏目编码、正文文字或状态含义。旧的 lime、sky、clay 变量为兼容历史页面保留，但均映射至中性色。禁止为三个栏目再分配三种主题色。

## 版式、字体与交互

- 统一系统无衬线字体。原先点缀的宋体口号回归同一字体系统。
- 标题以 500 字重为主；正文以 400 为主。首页文章标题约 28–40px，手机约 29–32px，正文在现有阅读尺度上保持舒适行距。
- 原大号浅色文章编号改为小型数字索引，避免与标题竞争。保留细分隔线与交替构图。
- 封面统一 4:3，桌面与手机不裁掉纸雕主体。圆角统一约 8px，封面外不叠加卡片阴影；画中物体自身的阴影用于说明材质。
- 交互只用文字、线条、填充明度和轻微缩放反馈，不引入新颜色。保留可见键盘焦点、44px 最小点击区、减少动态效果设置。
- 搜索、归档筛选、稍后读、目录和阅读进度沿用当前行为。
- 正文、个人姓名、经历与联系资料仍按原占位规则维护，不把视觉示例包装为个人成果。

## 封面制作约束

画布 640 × 480。背景使用统一中性径向渐变，纸张使用统一白至灰白渐变，阴影向右下。主体集中在画面中央，四周保留充足余量。左下只保留一条短线作为系列标记。禁止不同封面各自添加彩色底板、圈注、纹理噪点和字体装饰。

素材由 `tools/generate-art.mjs` 生成到 `public/images/`。调整整组光影时修改共享定义，再执行 `node tools/generate-art.mjs`；不要只为某一张引入另一套材质。该脚本仅生成当前原创示例，不会处理未来新增的个人照片。

实际作品和照片可以保留本身的色彩；使用统一留白和版式承载，不为了凑齐配色修改作品内容。

## 维护与验收

当前变量集中于 `design/tokens.css`，结构样式在 `src/styles/`。视觉对照板为 `design/art-review.html`。原 `style-guide.html` 与 `design/assets/` 属于 v1 历史材料。

检查四种页面、六张封面是否属于同一体系；验证 320、390、768、1440px 下无横向溢出；检查搜索、筛选、稍后读、目录、键盘和减少动态效果。最后执行类型与内容检查、自动化浏览器检查及静态构建。真实资料仍需补充，当前只交付本地版本。
