> 历史版本：现行博客已采用 [美术规范 v2](art-direction-v2.md)。本文件及 `style-guide.html` 保留用于追溯，不再作为当前配色依据。`tokens.css` 已更新到 v2。

**清晰而有生气 · Quiet precision, human warmth**  
版本 1.0 · 2026.10.18 · 配套文件：`style-guide.html`、`tokens.css`

## 01 · 设计结论

让访客先看见作品，再通过细节认识创作者。网站应当像一本精心编辑的个人作品集：画面清楚，节奏舒展，有真实的材料和生活气息。

推荐方向是**精确的展示秩序 + 自然的视觉温度 + 少量个人趣味**。将 Apple 产品宣传影像的主体控制、材料表现和视觉减法，与喜茶部分海报、包装和字体项目里的自然叙事、中文气质和趣味结合，最终建立属于个人的视觉系统。

参考对象限定为产品影像、广告摄影、海报、包装与字体作品。官网导航、网页结构和交互样式不作为采样对象。公开文章页面仅作为素材出处。

下文色值、比例、字号、网格和动效均为本项目的设计建议，不是两家品牌的官方规范。两家品牌都有多种视觉路线，本规范选择适合个人作品集的部分。

## 02 · 从参考素材到设计语言

| 参考对象 | 可观察的视觉特征 | 转译到个人主页 | 不直接移植的元素 |
| --- | --- | --- | --- |
| Apple，2024 iMac 产品发布影像 [R1] | 多色机身、同色配件；前后表面的色彩强弱有区分 | 同一项目用统一的背景与辅色；让作品细节成为画面中心 | 产品造型、品牌标识、完整广告构图 |
| Apple，Shot on iPhone 微距挑战作品 [R2] | 对日常材料、自然细节的近距离观看 | 用局部、过程、纹理说明创作能力；人像与生活照保留真实感 | 原摄影作品、品牌口号 |
| 喜茶，木姜子滇木瓜宣传海报 [R3] | 深色背景、原料静物、纸张与织物；以少量大字组织画面 | 作品旁呈现草稿、材料、观察记录；用真实过程补充结果 | 饮品杯型、商标、具体食材陈列 |
| 喜茶 × 方正字库，中式灵感体项目 [R4] | 从传统汉字中提炼当代字形，字体自身承担品牌表达 | 以现代中文排版为主体，少数章节使用宋体强调语气 | 品牌专属字体、未经设计的书法贴图 |

**设计推导：**专业感来自作品的清晰呈现与稳定的编辑秩序；亲近感来自真实的观察、材料和个人表达。以这两点作为合成依据，而不是把两套品牌符号拼在一起。

建议按“约 65% 精确秩序 / 25% 自然温度 / 10% 趣味细节”控制视觉重心。此比例是评图时的主观尺度，不是像素面积或品牌相似度。执行上：每屏一个主角、每屏至多一个装饰性笔触、每个作品保留自己的主题色。

## 03 · 气质与边界

| 关键词 | 应当呈现的样子 | 失控时的样子 |
| --- | --- | --- |
| 清晰 | 明确的主图、标题、行动入口 | 图文同时抢占注意力 |
| 精确 | 对齐稳定、裁切有意图、材料细节可信 | 大量装饰掩盖作品本身 |
| 自然 | 接近纸、植物、天空、陶土的颜色与触感 | 全站套米黄滤镜，作品失去原色 |
| 有人味 | 简短自述、真实过程照、一个个人笔触 | 每张卡片都有贴纸与涂鸦 |
| 当代中文 | 中文为主、字形端正、局部宋体 | 用生僻字、竖排和印章堆砌“中式” |

一屏内只设一个视觉峰值：可以是大标题、主图或强色块。其余元素降低强度。个人辨识度优先来自署名、作品、观点与摄影选择。

## 04 · 色彩系统

### 基础色与语义色

| 名称 / CSS token | 色值 | 使用位置 |
| --- | --- | --- |
| 纸白 / `--color-canvas` | `#F5F5F2` | 页面底色，保持微暖而接近中性 |
| 素白 / `--color-surface` | `#FFFFFF` | 图片底板、输入区、局部内容面 |
| 墨黑 / `--color-ink` | `#20231F` | 标题、正文、图标 |
| 石灰 / `--color-muted` | `#62675E` | 日期、项目类别、说明文字 |
| 结构线 / `--color-line` | `#D9DDD3` | 非必要装饰分隔，不单独承担控件边界识别 |
| 控件线 / `--color-border-control` | `#7C8276` | 输入框与空心按钮边界 |
| 森绿 / `--color-accent` | `#365B45` | 主要按钮、链接、选中态 |
| 深森绿 / `--color-accent-hover` | `#294735` | 主按钮悬停与按下态 |
| 芽绿 / `--color-lime` | `#DDE6AD` | 小面积纸签、局部背景，配墨黑字 |
| 雾蓝 / `--color-sky` | `#BDCFDF` | 可选项目底板，配墨黑字 |
| 陶土 / `--color-clay` | `#C66A4A` | 装饰圆点、插画局部，不承载小号文字 |
| 提示红 / `--color-danger` | `#A33131` | 表单错误文字及边界 |
| 深底 / `--color-night` | `#202820` | 可选的单个作品章节，配 `#F5F5F2` 字 |

界面主色只用森绿。芽绿、雾蓝、陶土按内容选用，每屏最多一种辅助色；作品原图不受这个数量限制。推荐全站界面底板约 80% 中性色、15% 作品色面、5% 强调元素，评图时目测即可。

**主题色跟随作品，界面语义保持稳定。**摄影项目可以用蓝底，品牌项目可以用红底，但返回、联系与当前导航仍使用同一套控件规范。首版采用浅色基底，深色只作为可选的作品章节；不在本阶段扩展完整深色模式。

### 对比与可读性

正文及小号说明按至少 4.5:1 的对比度验收；大字也优先沿用这个要求 [R5]。森绿按钮配白字；芽绿、雾蓝底配墨黑。浅色分隔线不能替代清楚的输入框边界。链接同时使用下划线或明确的文字提示。

基础色实算对比度：墨黑 / 纸白约 14.55:1，石灰 / 纸白约 5.31:1，白字 / 森绿约 7.67:1。控件线 / 素白约 3.95:1，用于边界而非小号文字。叠加透明度、纹理或照片后须重新验算。

## 05 · 字体与中文排版

**默认采用系统无衬线字体。**中文在 Apple 设备上优先 PingFang SC，Windows 上优先 Microsoft YaHei；英文与数字沿用系统 UI 字体。主标题使用 600–650 的视觉字重，正文 400。不同平台不保证字形完全一致，须在 Windows 与 macOS 上核对换行；缺少某字重时选择实际可用的最近字重。

宋体只用于“关于我”、观察手记或章节引言，每屏至多一个短句。系统回退采用 Songti SC / SimSun。需要跨设备稳定字形时，再引入拥有相应网页使用许可的字体，并先验证中文子集加载和回退效果。

| 用途 | 桌面字号 / 行高 | 手机字号 / 行高 | 规则 |
| --- | --- | --- | --- |
| 首屏主标题 | 72px / 1.12 | 40px / 1.18 | 桌面最多 2 行，手机最多 3 行 |
| 页面标题 | 56px / 1.15 | 36px / 1.22 | 优先自然断句 |
| 章节标题 | 36px / 1.25 | 28px / 1.30 | 与下段距离 24px |
| 作品标题 | 24px / 1.40 | 22px / 1.40 | 项目名称保持完整 |
| 正文 | 18px / 1.80 | 16px / 1.80 | 长文宽度上限 44rem |
| 日期、图注 | 14px / 1.60 | 14px / 1.60 | 使用石灰色，不再降低透明度 |
| 导航、按钮 | 15px / 1.40 | 15px / 1.40 | 500–600 字重 |

中文标题字距为 0；需要收紧的英文大标题可设为 -0.025em。不要给中文标题套统一负字距。英文眉题可以用 0.08em 字距，但只做辅助信息。中英文字体基线和数字高度需实际核对。

尽量让中文标点不孤悬于行首；主标题允许按语义设置受控断句，但不能把桌面的强制换行直接沿用到手机。长标题优先增加行数，不压缩文字或缩小为装饰性细字。

## 06 · 构图、网格与页面节奏

将“海报”的单一主角、“产品摄影”的细节展示与“作品集”的阅读顺序结合。单张海报的密集信息需要拆分为多个网页段落，而主图的视觉重心可以保留。

| 视口宽度 | 内容宽度 / 边距 | 网格 | 栏间距 / 章节间距 |
| --- | --- | --- | --- |
| ≥1200px | 最大 1200px；两侧至少 48px | 12 栏 | 24px / 128px |
| 768–1199px | 两侧 32px | 8 栏 | 24px / 96px |
| <768px | 两侧 20px | 4 栏 | 16px / 72px |

空间基准为 4px。常用间距依次为 8、12、16、24、32、48、64、72、96、128px。首屏不锁定为固定 100vh；内容较长时自然延展，并能看见后续作品入口。

桌面首屏建议文字 5 栏、作品图 6 栏、中间空 1 栏。作品列表用稳定的双列结构，允许一个精选项目通栏；少量不对称来自图像内容与留白，不采用交错瀑布流。手机顺序统一为“身份 → 标题 → 简述 → 查看作品 → 主图”。

长文使用单列阅读宽度。图片可以突破文字宽度，但说明文字回到统一对齐线。留白集中在章节之间，同组标题、标签和说明保持接近，避免所有元素等距离散开。

## 07 · 影像与材质

### 三类素材

1. **结果图：**完整作品、产品界面、实物成果。背景简洁、边缘清楚、色彩准确。每个项目至少一张完整全貌。
2. **过程图：**草稿、材料、代码输出、实验或推敲过程。保留与项目有关的真实痕迹；配一句说明它回答什么问题。
3. **个人图：**工作状态、生活观察、个人收藏。自然光、简单环境、不过度磨皮；只在介绍本人或观点时出现。

同组照片固定白平衡与主要光向。柔和侧光是默认选项；材质项目可以保留更强的明暗对比。金属用边缘高光表现，纸张用真实折痕或扫描纹理表现，玻璃用透光与环境反射表现。避免给所有作品加相同的虚拟投影与滤镜。

作品封面统一 4:3；详情页主图优先保留原始比例，也可用 16:10 横图；肖像建议 3:4。封面可有意裁切，详情必须提供完整图。包含界面文字、图表或排版的作品使用 contain，不能用 cover 切掉信息。

视觉样张中的“折光”和“生长记录”为原创形式示意，不代表用户已有项目。开发正式主页时换成真实作品；没有素材时先保留中性占位，不伪造项目成果。

### 图形、肌理与图标

图形只选一种个人母题，例如“观察的括号”“一条生长线”或“手写圈注”。本方案推荐细线圈注：仅用于一条自述或一张过程图；不在导航、表单与正文后铺满。

纹理优先使用真实作品或扫描材料，集中在图片内部。页面文字底层保持纯色。图标统一 20 / 24px、约 1.75px 描边、圆角端点。箭头、加号等来自同一套图标；装饰图形与功能图标有清楚区别。

## 08 · 组件视觉规范

| 组件 | 默认视觉 | 悬停 / 焦点 / 其他状态 |
| --- | --- | --- |
| 导航 | 64–72px 高；姓名文字标识；作品 / 关于 / 联系 | 当前项有短下划线；焦点有 2px 森绿轮廓；手机保持文字入口或提供带文字的菜单 |
| 主按钮 | 森绿底、白字；高 48px；横向内边距 22px；圆角 12px | 悬停深森绿；按下轻微颜色变化；加载保留原宽并显示“处理中” |
| 次按钮 | 透明底、墨黑字、控件线边框；同高同圆角 | 悬停素白底；焦点不改变尺寸 |
| 文字链接 | 森绿字、下划线；15–18px | 悬停深森绿；visited 可保持同色，依靠浏览器历史提供常规行为 |
| 作品入口 | 图片圆角 16px；标题与元信息在图外；无整块白卡底 | 仅精细指针设备图片放大 1.02 倍；标题加下划线；键盘焦点覆盖入口范围 |
| 分类标签 | 14px；高至少 32px；轻底色或文字 | 交互型筛选增加至 44px 点击区；选中同时有勾选或下划线 |
| 输入框（如采用联系表单） | 高至少 48px；圆角 12px；明确标签；控件线边框 | 聚焦森绿边框与外轮廓；错误用提示红、错误文字及图标；不只变颜色 |
| 空内容 / 图片失败 | 保留图片比例；显示清楚的说明与重试入口 | 不使用持续闪动的装饰；不让布局突然塌陷 |

阴影仅用于悬浮层与必要的材质表现。常规作品卡片不叠加底板、边框与投影。正文阅读区采用 0px 圆角；图片用 16px，组件用 12px，真实胶囊标签才用 999px。

联系区首版可只使用公开邮箱链接与社交主页。仅在确有收集需求时增加表单，并按同一套组件状态实施。

## 09 · 动效语言

动作表达“我可以被操作”“新的内容到了”或“正在切换作品”。不让装饰性运动抢过作品。

| 场景 | 时长 | 幅度 / 曲线 | 限制 |
| --- | --- | --- | --- |
| 颜色、边框状态 | 160ms | ease-out | 不改变布局 |
| 作品悬停 | 240ms | 图片 scale 1 → 1.02 | 只在 hover:hover 且 pointer:fine 时启用 |
| 章节首次出现（可选） | 420ms | opacity 0 → 1；Y 12px → 0；cubic-bezier(.22,1,.36,1) | 只执行一次；正文初始可见，脚本就绪后再增强 |
| 图片切换（如有） | 240ms | 交叉淡入 | 保持同高容器与可见的前后按钮 |

不设自动播放声音、自定义鼠标、滚动劫持、无限漂浮物或强制加载开场。普通页面无需视差。系统开启减少动态效果时，移除位移、缩放、滚动平滑与非必要过渡。

## 10 · 页面应用方案

### 首页：身份 → 作品 → 人 → 联系

**首屏。** 姓名 / 专业方向、小段自述、一个“查看作品”入口和一张精选作品图。标题示例：“把观察，做成作品。”具体职业与观点在有真实内容后替换，不把这句话当固定品牌口号。

**精选作品。** 先展示 3–5 项。标题、类别、年份清楚可见；不靠悬停才显示项目信息。每项用一句话说明解决的问题或探索的主题。分类较少时不加筛选器。

**关于。** 一张真实照片或一张能代表创作习惯的过程图；80–150 字介绍；2–3 个能被作品证明的能力标签。可加一个短宋体句子，作为全页最有人味的停顿。

**联系。** 明确说明合作意向或交流方式，使用真实、允许公开的联系方式。页脚只保留必要的署名和链接。

### 作品详情：结果 → 背景 → 关键选择 → 过程证据 → 回看

开头一张完整成果图，随后列出角色、时间、范围与协作方式；接着解释 2–3 个关键选择，用过程图支撑；末尾给出结果或反思及下一件作品。尚无量化结果时陈述观察，不用虚构数据装点页面。

正文不为了保持“海报感”拆成大量孤立口号；大图间的说明应帮助读者理解设计。界面、研究、摄影、写作等不同作品允许不同的详情叙事，统一的是排版与导航。

### 文案语气

使用第一人称、短句和具体动作。写“我把三个入口合并成一个”，比“重塑体验边界”更能展示判断。入口使用“看作品”“了解我”“联系我”等可预期用语。具体事实、署名、项目名均由真实资料替换。

## 11 · 手机与无障碍细则

手机以 390px 为主设计宽度，同时验收 360px 和 320px。320px 时允许内容变长，不允许横向页面滚动。按钮和导航建议至少 44×44px 可点击区域；这是本项目的舒适度目标，WCAG 2.2 AA 的目标尺寸条款为至少 24×24 CSS px，并包含例外条件 [R6]。

交互信息必须在触屏与键盘下同样可得；不以鼠标悬停、颜色或动效作为唯一信息来源。作品链接拥有完整可读名称；装饰 SVG 对辅助技术隐藏，有内容的图片附有描述。键盘焦点清楚且不被吸顶导航遮挡。

标题可扩大、正文可缩放至 200%；不把正文烘焙到图片中。文字覆盖图像时提供稳定纯色底或渐变遮罩并单独验算对比；优先把说明放在图片外。

## 12 · 素材与开发交付

### 需要准备的真实素材

- 个人姓名或署名、专业方向、简介、联系方式与公开社交链接。
- 3–5 个精选项目，每个包含项目名、年份、个人角色、一句话摘要、封面和完整成果图。
- 每个项目 2–4 张有解释价值的过程图；有协作者时明确署名与贡献。
- 一张肖像或工作状态图；一个可持续使用的个人图形母题。

### 文件和导出

| 资产 | 建议交付 | 开发要求 |
| --- | --- | --- |
| 作品封面 | 原始文件 + 1600×1200px 导出版 | 提供 480 / 800 / 1200 / 1600 宽响应式尺寸；单张优先控制在 250KB 内，文字可读性优先 |
| 详情主图 | 原始比例，长边约 2400px | 图片标注 width / height；重要文字图允许更高体积或无损格式 |
| 肖像 | 1200×1600px | 提供手机裁切焦点，不把人脸放在边缘 |
| 图标 / 个人标识 | SVG | 统一 viewBox、描边、颜色变量 |
| 可选视频 | MP4 + 静态封面 | 默认用户主动播放；提供字幕或等价文字说明 |

照片优先导出 AVIF / WebP 并保留兼容回退；含小字、细线的作品按实际清晰度选择 PNG 或高质量 WebP。优先加载首屏主图；屏下图延迟加载。图片加载失败仍保留标题和项目链接。

开发直接引用配套 `tokens.css` 作为初始变量，按项目技术栈映射。它是起始样式，不是完整组件库。原生系统字体无需下载；如加入网页字体，应交付所需授权、字重与子集配置。配套视觉样张不依赖外部图片或字体，可以离线查看。

### 设计与开发一致性检查

- [ ] 首屏一眼能看出“谁、做什么、如何看作品”；没有遮住作品的开场动画。
- [ ] 使用真实作品，或清楚标记尚未替换的示意内容。
- [ ] 同一页面没有多种圆角、阴影、描边语言竞争。
- [ ] 作品封面比例一致；详情图完整；图文不被裁切。
- [ ] 森绿只承担稳定的品牌与交互语义，辅助色按章节有节制出现。
- [ ] Windows、macOS 与手机上的中文没有缺字、挤压或不合理断行。
- [ ] 320 / 360 / 390 / 768 / 1440px 宽度下无横向溢出。
- [ ] 链接、筛选、表单具有键盘焦点与触屏可用状态。
- [ ] 对比、减少动态效果、200% 文字缩放与图片失败状态通过人工检查。
- [ ] 项目角色、图片来源、字体与个人标识清楚可追溯。

## 13 · 易偏离方向的做法

**整站全白 + 超大标题 + 灰色小字。**容易只有“极简”的外观而没有个人内容。改为一个有观点的标题、一张强作品图、清楚可读的说明。

**整站奶油色 + 叶片 + 手写体。**容易让个人作品集呈现茶饮品牌模板。自然感改由过程照片、材料细节和一个个人笔触承担。

**每个项目都是同一种悬浮样机。**会抹平不同作品的差异。为每个项目选一张最能解释其价值的图，保持外部编辑秩序一致。

**大量毛玻璃、霓虹渐变和视差。**这些并非本方案从产品和海报中选择的核心语言。只在作品本身有相关主题时使用，界面回到安静基底。

**为了风格压缩阅读。**正文过小、灰字过浅、图注只在悬停出现，都会妨碍作品被理解。阅读与操作清晰度优先于视觉修饰。
